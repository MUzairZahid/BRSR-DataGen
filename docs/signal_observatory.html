Data provenance & what this model represents
Real samples. Transparent transformations.

All 1,024 complex values per component come from BRSR-DataGen. Signals are displayed in units of clean RMS, with the same scale applied to every component. These are seeded demonstration samples, not rows from the published test set.

The SNR slider rescales the fixed artifact realizations by 10^((−3 − target)/20). It does not invent a new waveform or noise realization. The measured SNR uses the actual combined error over I and Q; it can differ from the requested full-blend target because components have cross-terms.

A synthetic additive model, not a propagation simulator.

The benchmark's echo uses a source segment starting later than the clean segment: source[start + offset + n]. We retain this legacy convention and call it a source offset, rather than claim a causal physical delay. There are no simulated buildings, ranges, Doppler shifts or antenna patterns here.

Power fractions are applied as square-root amplitude gains. The interference bank has 50 rows (35 distinct signals). The LFM uses the legacy benchmark amplitude convention; this view normalizes it. The Costas example uses a validated sequence, 1–2–4–3.

Only three of the dataset's twelve waveform classes are featured. The generator also includes Frank, P1–P4 and T1–T4, and supports all seven nonempty artifact combinations.
