Data provenance and what this model represents
Real samples, transparent transformations.

All 1,024 complex values of every component come from BRSR-DataGen. Signals are shown in units of clean RMS with one scale for every component. These are seeded demonstration samples, not rows of the published test set.

The SNR slider rescales the fixed artifact realisations by 10^((−3 − target)/20); it never invents a new waveform or noise draw. Measured SNR uses the actual combined error over I and Q, so it can differ from the requested full-blend target because the components have cross-terms.

Samples are stored in the page as 16-bit integers with a per-component scale (maximum quantisation error below 3.1 × 10⁻⁵ of each component's peak), which keeps this single file small enough to load on a phone.

A synthetic additive model, not a propagation simulator.

The benchmark echo is a source segment that starts later than the clean segment: source[start + offset + n]. The page keeps that legacy convention and calls it a source offset rather than a physical delay. The towers, building and moving particles are visual metaphors; no ranges, Doppler shifts or antenna patterns are simulated.

Power fractions are applied as square-root amplitude gains. The interference bank has 50 rows (35 distinct signals). The LFM uses the legacy benchmark amplitude convention, normalised here for display. The Costas example uses a validated sequence, 1–2–4–3.

Spectrograms use a 64-point Hann window with a 4-sample hop over the complex signal (241 frames, centres 0.315–9.915 µs; bin centres −50 to +48.4 MHz) and are drawn at that native resolution without smoothing. Colours are fixed from −40 to 0 dB relative to the clean spectrogram peak of the selected waveform; both panels share the scale.

Component switches isolate parts of the same blend; they do not draw a new composition or redistribute power. Next sample loads a different stored realisation with the same waveform parameters.
